# Academic Resource Exchange (Android Application)

An Android-based application that enables students to buy, sell, donate, or rent academic resources such as books, notes, and study materials.

---

## 📌 Project Overview

Academic Resource Exchange is designed to solve accessibility and affordability challenges faced by students.  
The platform allows users to list academic materials and connect with other students for exchange, purchase, or rental.

The application provides a simple and user-friendly interface to manage listings and interactions efficiently.

---

## 🚀 Key Features

- User registration and login
- Post listings for books, notes, and academic materials
- Buy, sell, donate, or rent resources
- View available listings with details
- Real-time data storage and retrieval
- Clean and intuitive Android UI

---

## 🛠 Technologies Used

### 📱 Frontend
- Android (Java)
- XML Layout Design
- Android Studio

### ☁ Backend & Database
- Firebase Authentication
- Firebase Realtime Database / Firestore
- Firebase Storage (if images are used)

---

## 🏗 Application Workflow

1. User registers or logs in.
2. User can create a listing (buy/sell/rent/donate).
3. Listing data is stored in Firebase.
4. Other users can browse and interact with available resources.
5. Data updates dynamically in real time.
